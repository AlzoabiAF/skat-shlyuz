# Скат-Шлюз

Проект № 2 для практической работы «Разработка безумного транспортного средства». Стихия — вода. Автор ТЗ — Альзоаби Адель Фаридович, БСБО-16-23.

Подвижный шлюз капсулы выравнивает уровень воды перед воротами. Подъём расходует запас, спуск возвращает часть воды, а крайние участки служат причалами для пополнения бака.

Версия 0.1.1 подготовлена к ревью ТЗ на ПР1. В наборе 12 проверок отдельных правил и один сквозной сценарий. После согласования ТЗ разработчик реализует класс `SkateLock` в `skate_lock.py`. Тесты используют Python 3.10+ и стандартный `unittest`.

```sh
python -m compileall -q tests
python -m unittest discover -s tests -t . -v
```

До появления `skate_lock.py` полный запуск обнаруживает 13 тестов и останавливает каждый в `setUp` с ошибкой импорта.
